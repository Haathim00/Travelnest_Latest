# 🌍 TravelNest

TravelNest is a smart travel planning web application which helps users to find their destination, calculate their travel budget, provide them travel ideas, and recommend them their travel based on their preferences and mood. It offers a interactive and easy to use experience for travelers to plan their next trip.

## 🚀 Live Demo

🔗 https://haathim00.github.io/Travelnest_Latest/

The website's home page is both modern and responsive.The homepage is modern and responsive.

Estimate your journey costs with this flight budget calculator.

- 🤖 Travel idea generator
